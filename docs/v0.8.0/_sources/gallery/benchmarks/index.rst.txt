Benchmarks
==========

This category contains reproducible performance benchmarks for PackLab's
public workflows. Each benchmark should state the machine and software
environment, workload parameters, repetitions, timing method, and the metric
being reported (for example runtime, throughput, or peak memory).

Benchmarks measure computational cost. They are distinct from the validation
examples, which assess numerical resolution or compare models with matched
physical inputs.

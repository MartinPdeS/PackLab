Scattering
==========

Examples for the optional PyMieSim-backed scattering workflow. Install the
extra before running them:

.. code-block:: console

   $ pip install "packlab[scattering]"

The single-sphere examples explore size, wavelength, and optical contrast.
The mixture examples compare independent scattering with a structure-corrected
Percus--Yevick reference. The latter is an analytical calculation, not a
simulation of an RSA configuration.

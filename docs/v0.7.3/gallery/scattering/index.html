Scattering#

Examples for the optional PyMieSim-backed scattering workflow. Install the extra before running them:

$ pip install "packlab[scattering]"

The first example treats individual sphere sizes independently. The second combines the optical amplitudes with a Percus–Yevick mixture structure factor; it is an analytical scattering calculation, not a simulation of an RSA configuration.

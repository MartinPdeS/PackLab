# JOSS manuscript

This directory is reserved for a possible Journal of Open Source Software
submission. JOSS uses `paper.md` and `paper.bib`, not the longer SoftwareX
LaTeX manuscript.

Before drafting the JOSS paper, confirm with the editors that the preserved
public development record satisfies the journal's development-history policy.
The eventual paper must follow the current JOSS paper template and remain
between 750 and 1750 words.

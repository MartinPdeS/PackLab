Examples
========

The gallery is organised by the question each workflow answers:

* **Monte Carlo** creates and inspects explicit RSA sphere packings.
* **Analytical** evaluates Percus--Yevick mixture models and scattering
  quantities without generating a packing.
* **Validation** compares Monte-Carlo estimates with their analytical
  counterparts.

Start with the minimal RSA example, then use the validation examples when you
want to assess agreement between the two approaches.

Monte-Carlo hard-sphere workflows
=================================

Examples that generate explicit random sequential adsorption configurations.
They cover the basic simulation setup, periodic boundary conditions, radius
distributions, visualisation, and pair-correlation estimates. The Metropolis
example starts from an RSA configuration but then uses a separate equilibrium
hard-sphere workflow with fixed particle count and radii.
